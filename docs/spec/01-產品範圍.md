# 01 產品範圍

## 定位

**收錄過去到未來的主機、掌機與 PC 遊戲資料庫；月曆與時間軸是檢視同一份上市資料的兩種方式；會跟著異動（尤其是延期）自動更新的 iCal 訂閱，是核心交付物。**

另外兩個入口：Discord Bot（把上市與活動帶進玩家的伺服器）、帳號功能（收藏、遊玩紀錄、追蹤）。

## 功能總覽

| 領域 | 功能 | 文件 |
| --- | --- | --- |
| 資料庫 | 遊戲、平台（含硬體上市日、世代、家族）、公司、系列、類型／主題、相似遊戲、DLC、語言支援、媒體、商店與官網連結 | 03、04、06 |
| 檢視 | 月曆、議程式時間軸、硬體世代時間軸（後置）、瀏覽篩選、熱門榜、搜尋（中英日） | 06 |
| 活動 | 發表會、展會、頒獎典禮；入圍與得獎名單 | 04、13 |
| 評分 | IGDB 分數（預設）、Metacritic（可選）、玩家平均（另列） | 05、13 |
| 帳號 | Discord／Google／Twitch／Twitter(X)／Steam／Xbox／Email 登入，Steam／Xbox 遊戲庫匯入 | 09 |
| 收藏 | 多個具名清單、遊玩紀錄（狀態、平台、耗時、評分、評論） | 09 |
| 追蹤 | 遊戲、活動、平台、系列、公司 → 個人 iCal、Email、Discord 私訊 | 09、08、11 |
| Discord | 斜線指令、一鍵建立 Discord 活動、定時公告、伺服器共同追蹤、反應身分組 | 10 |
| 社群 | 公開評論與按讚、公開清單分享、追蹤其他用戶、動態 | 13 |
| 維運 | 管理介面、資料更正回報、通知 | 11、12 |

## 不做的事

| 不做 | 理由 |
| --- | --- |
| Google 日曆一鍵加入（template URL、Calendar API） | iCal 訂閱已涵蓋，且能反映延期（D12、D13） |
| PlayStation／Nintendo 帳號綁定 | 無官方第三方管道（D18） |
| Bot 自動大量建立 Discord 活動 | 活動一律由人按按鈕建立（D14） |
| 收錄傳聞主機 | 只收官方公布者（D22） |
| 收錄手機平台 | 產品擁有者決定，2026-10-12 |
| 用戶投稿修改遊戲資料 | 改走「資料更正回報」由管理員審核（12） |
| 把玩家評分混進專業評分 | 玩家平均另列，不進評分來源選單（D68） |
| 即時價格、特價、聯盟分潤連結 | 非商業定位；Twitch 條款疑慮（91 §授權） |
| 語言支援篩選 | 涵蓋度未知，只做顯示（D57） |
| 鏡像圖片 | 只存 URL |
| 使用 RAWG | D59 |

## 資料來源

| 用途 | 來源 | 備註 |
| --- | --- | --- |
| 遊戲、平台、上市日、活動、公司、系列、連結、語言 | IGDB API | 唯一主資料來源（D1）；非商業免費 |
| 評分 | IGDB `aggregated_rating` | 隨遊戲查詢帶出，樣本數少 |
| 評分（可選） | Metacritic 抓取 | 預設關閉，法律風險見 05 |
| 頒獎名單、活動類型、台灣上市日 | 人工維護 | IGDB 沒有 |
| 遊戲庫匯入 | Steam Web API、Xbox Live API | |
