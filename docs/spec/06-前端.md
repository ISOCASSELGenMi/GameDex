# 06 前端

Next.js（App Router）＋ TypeScript ＋ Tailwind CSS，單體應用。`app/` 只放薄路由（02），實際內容在 `modules/<name>/ui/`。頁面元件呼叫 Repository／Use Case 函式，**不寫 `db.select()`**。版面的可變區域（header 右側、遊戲頁動作列與區塊）用 UI slot，`catalog` 版面不寫死任何可選功能。

## 月曆

- **不用通用行事曆套件**，自己刻 CSS Grid。
- **每個日期一格只顯示一款遊戲**（封面滿版、名稱、平台、標籤），同日多款在**格內左右切換**（按鈕、方向鍵、觸控滑動），格底以點點或「3 / 24」顯示位置；今天有明顯標示；換月有轉場（D84）。
- 伺服器 HTML 只送每天的第一款與當日總數；其他款切換時才由 `GET /api/v1/calendar/day` 載入（07），同一套篩選與 §聚合規則。月曆頁 HTML 預算約 250 KB（改版前整月 1.7 MB）。
- **模糊日期不進格子**，列在月曆下方「本月未定日」區塊，依 `releaseDate` 所在月份歸屬：月精度 → 該月；季／年 → 期間最後一個月。數量 ≤ 24 顯示完整卡片與預覽卡，更多時只送精簡列。
- 手機寬度：改為橫向卡片列表，仍是一日一款＋可切換。
- 無障礙：每格 `role=group`、可及名稱含日期與款數；方向鍵切換同日款數；目前顯示的款以 `aria-live` 宣告。
- 支援 §篩選，條件在 URL，切換月份保留。點項目開側邊預覽卡（追蹤按鈕 slot、Discord 活動 slot）。

## 時間軸

**以週為單位的垂直中軸**（D84，參考 IGDB timeline）：

- 上一週／下一週、跳到指定日期、回到今天（今天以 UTC 日期計）；網址 `?week=YYYY-Www`（ISO 週，週一起算），舊連結 `?at=YYYY-MM-DD` 取該日所在週。有 JS 時就地切換（`GET /api/v1/timeline/week`＋`history.pushState`），沒有 JS 時是一般連結。
- 每個發售日一張封面卡片，**左右交錯**掛在中軸、以橫線連到日期節點；卡片頂端顯示當日上市數；同日多款沿用月曆的格內切換與 day API。手機中軸靠左、卡片單側。
- 上方平台種類快速篩選＋既有篩選面板。日期只確定到月／季／年的遊戲不在時間軸（請看月曆）。
- 無障礙：`<ol>`、日期節點標題含完整日期、新週載入以 `aria-live` 宣告。HTML 預算 < 200 KB。

**硬體世代時間軸**（後置）：以 `platform_families` 為列、`platform_release_dates` 到 `discontinuedOn` 為條，世代為背景分欄。

## 聚合規則

`release_events` 是遊戲 × 平台 × 地區 × 階段，不聚合會讓一款遊戲出現十幾次。**月曆、時間軸、Discord `/upcoming`、公開 iCal 共用**，寫成 Repository 單一函式 `repository/release-aggregate.ts`：

1. 每個 (遊戲, 平台, 階段) 挑一筆：來源仍存在（active）優先於 removed（被 IGDB 覆蓋的 manual 為 removed，D75）；其次 `manual` 優先於 `igdb`；其次使用者偏好地區 → `WW` → 最早日期（`DISTINCT ON` ＋ 優先序）。
2. 同一款遊戲、同一天的多個平台合併成一張卡（平台以 chip 呈現）；不同天分開。
3. 地區偏好 = 使用者設定 > 瀏覽器語系推導 > `DEFAULT_REGION_PREF`（`WW`）。

## 遊戲詳情頁

封面、名稱（依語系）、簡介（原文標示）、平台（連到平台頁）、年齡分級、截圖與預告片；主分數與所有可見來源（05；分數區永遠顯示，沒有分數時欄位留白）；**玩家平均**（slot）；上市日列表（依平台分行，含延期紀錄與階段標示；同 (平台, 地區, 階段) 有 active manual 列時不列 igdb 列，12）；開發／發行商；**商店與官網連結**（依偏好地區排序、失效連結標示）；同系列作品；相似遊戲；DLC／額外內容（經 `parentGameId` 反查）；即將亮相的活動；**入圍與得獎紀錄**（awards slot）；**語言支援**；**玩家評論**（social slot，劇透預設折疊）；回報資料有誤（12）。

**封面圖**：IGDB 圖片 URL 換尺寸 token（`t_thumb`、`t_cover_big`、`t_1080p`）依 viewport 選用。著作權屬發行商，不做衍生用途，收到下架要求就下架。

### 語言支援區塊

- 列 = 語言，欄 = 介面／字幕／語音，格 = ✓ 或空白（文字＋圖示）。只列有資料的語言。
- **三種狀態分清楚**：某類型有資料 → 列出；某類型完全沒資料 → 該欄「未提供資料」（**絕不顯示「不支援」**）；三類都沒資料 → 整區「尚無語言資料」＋補充連結（回報 `language_support`）。
- 語言名稱用 `Intl.DisplayNames([locale], { type: "language" })` 依網站語言顯示，附自稱；當前網站語言置頂。
- 卡片最多顯示 6 個語言標籤，其餘「＋M」。

## 活動

- 列表條件 `COALESCE(end_time, start_time) >= now()`，進行中的多日展會不會被藏起來。可依類型（發表會／展會／頒獎）篩選。
- `start_time` 為 NULL 顯示「時間未定」，不進 iCal。
- 活動時間依使用者本地時區顯示（登入者用帳號時區，否則瀏覽器時區）：伺服器 HTML 輸出 UTC 的 `<time datetime>`，client 端改寫為本地時間。第一輪是本地時間主行＋UTC 小字；**第二輪（D85）改為只顯示一行本地時間並標註時區（例如 GMT+8）**。格式化唯一實作 `formatEventTimeText`。IGDB 時區縮寫只做附註。
- 詳情頁：時間、直播連結、主辦、相關遊戲、同系列歷屆；頒獎典禮另有獎項區（13）；追蹤與建立 Discord 活動按鈕（slot）。

## 篩選

- 平台種類分組：混合型（`hybrid`，如 Switch、Switch 2）**同時歸入「家用主機」與「掌機」**，不單獨成組；篩選家用主機或掌機都含 hybrid（舊網址 `platformKind=hybrid` 仍接受，只比對 hybrid）。分組邏輯唯一在 `catalog/domain/platform-groups.ts`（D84）。

月曆、時間軸、瀏覽、熱門榜、API、Discord 公告共用單一 `FilterSpec`（zod，放 `packages/api-contract`）。

- **URL 是唯一狀態**：`?platform=ps5,switch&genre=rpg&stage=full`，值一律 slug，可分享、可上一頁還原；切換月份與檢視時保留。
- **同維度 OR、跨維度 AND**。

## 瀏覽與搜尋

- 排序 MVP 只開放 `popularity | release_date | name`，**不開放依評分**（D27）。
- **搜尋**：`games.searchText` = NFKC＋小寫，串接 `name`＋`alternativeNames`＋`game_localizations.name`，建 GIN trigram 索引，同步時更新。
- 🧪 **中日文**：資料庫必須是 UTF-8 locale（`C`／`POSIX` 下 `pg_trgm` 對中日文完全失效）；`C.UTF-8` 可用但相似度偏低，所以 `searchText` 與查詢字串都經同一個 `tokenizeForSearch()`：連續 CJK 字元拆成相鄰雙字（bigram），拉丁文不變。只輸入 1 個中文字時退回 `ILIKE`。不夠用再考慮 `pg_bigm`／PGroonga／Meilisearch（D28）。
- 搜尋不分語系，結果以當前語系名稱顯示；名稱排序以原文 `games.name`，UI 標示「依原文名稱排序」。
- 全站搜尋涵蓋遊戲、平台、公司、系列、活動。

## 熱度顯示

- 圖示＋文字（「熱度 4/5」）＋`aria-label`；`heatLevel = 0` 不顯示。格子與時間軸只顯示小圖示。
- 追蹤人數 ≥ `FOLLOW_COUNT_MIN_DISPLAY` 才顯示（`Intl.NumberFormat(locale, { notation: "compact" })`）；`accounts` 停用時不顯示。
- 「上升中」：`site_follows_7d` 在群內前 5%。
- 熱門榜 `/trending`：依 `site_follows_7d`（`accounts` 停用時依 `popularityScore`），ISR 15 分鐘。
- 熱度每小時更新，UI 不暗示即時。

## 多語系

**三條原則**

1. **網站語言是唯一語言來源**（D35）：右上角語言選單切換，我方控制的所有顯示內容一律用該語言。
2. **語言只由 URL 前綴決定**（D36）：同一網址不依 Cookie 或 `Accept-Language` 變內容，否則共用快取會把錯的語言給別人。
3. **資料庫不存已本地化的顯示字串**（D37）。

**無前綴入口（如 `/`）的語系決定順序**：Cookie `sok_locale` → `users.locale`（accounts 啟用時，經 `RequestContext`）→ `Accept-Language`（`zh-TW`／`zh-HK`／`zh-Hant` → `zh-Hant`；`en-*` → `en`；`ja*` → `ja`）→ `DEFAULT_LOCALE`（`zh-Hant`）。302 導向、`Cache-Control: private`、`Vary: Accept-Language, Cookie`。帶前綴的網址一律不導向，偏好與網址不同時以網址為準。

**語言選單**：一般連結（`<a href="/ja/<同一路徑>">`），不需要 JS；以各語言自稱顯示。點選時由專用端點寫 Cookie `sok_locale`（`SameSite=Lax`，1 年），登入者同時更新 `users.locale`。一般頁面回應不寫 Cookie（§SEO 與快取）。

**遊戲名稱解析鏈**（同步時預先算好寫入 `games.displayNames`，列表不必 JOIN）：

1. `game_localizations` 對應 locale 的名稱。IGDB 只提供 Japan → `ja`、Korea → `ko`（只存不顯示）；**沒有任何中文地區**，`zh-Hant` 名稱靠人工補登與使用者回報。
2. `alternativeNames` 中屬於該語系者：`comment` 是自由文字且繁簡標示不可靠，只標「Chinese title」的要人工確認才當 zh-Hant 顯示；標 simplified 的只當搜尋別名。腳本判斷（含假名 → ja）只作最後手段 ❓。不做簡轉繁。
3. `games.name`。

  | quarter | 2027 年第 2 季 | Q2 2027 | 2027年第2四半期 |

## SEO 與快取

- 每個語系獨立網址＋`hreflang`＋`x-default`＋自我參照 canonical。
- sitemap 分片（單檔 ≤ 50,000 URL／50 MB ✅）＋ sitemap index，sitemap 以 `xhtml:link` 列各語系替代網址。
- 詳情頁 ISR（1~24 小時）＋`Cache-Control: s-maxage, stale-while-revalidate`。
- JSON-LD（`VideoGame`）、OG tags。
- **硬限制** ✅：回應帶 `Set-Cookie`，或 `Cache-Control` 為 `private`／`no-store`／`no-cache`／`max-age=0` 時 Cloudflare 不快取。**可快取頁面一律不送 `Set-Cookie`**。Cloudflare 規則見 16。
- 頁尾署名「Data from IGDB.com」。

## 無障礙與響應式

目標 **WCAG 2.2 AA**（D52）。

- 手機寬度月曆改議程式清單。
- 觸控目標至少 24×24 CSS px ✅；主要操作建議 44×44。
- 月曆依 ARIA grid 模式：方向鍵移動、Enter 開啟；全站不靠滑鼠；焦點可見；「跳到主要內容」。
- 熱度、階段、延期／取消、遊玩狀態都有文字或圖示，不只靠顏色。
- 對比 ≥ 4.5:1（大字 3:1）；支援深色模式；尊重 `prefers-reduced-motion`。
- 篩選用原生 `fieldset`／`checkbox`；結果變更以 live region 告知筆數。
- 封面 `alt` = 遊戲顯示名稱；裝飾圖 `alt=""`；外語文字標 `lang`。
- 行動裝置 Core Web Vitals 達「良好」；圖片延遲載入、指定尺寸。
- CI 跑自動化檢查（`npm run test:a11y`，工具選型 ⚠️）；發布前人工檢查：純鍵盤走完月曆 → 詳情 → 追蹤，並抽查一種螢幕閱讀器。
