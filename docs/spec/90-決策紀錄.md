# 90 決策紀錄

**目的**：防止重新討論已討論過的問題。每一條都比較過替代方案。實作時對某個做法有疑慮，先查這裡；確定要推翻，新增一條並在舊條目標「作廢，見 Dxx」。產品擁有者的決定另見 01 的產品決策表（P 編號）。
