# UI／UX 設計方向（使用者指示，2026-10-15）

> 尚未執行。**正式規劃／改版網站頁面設計時，依本文件設計**；與規格書（`docs/spec/`）衝突時先問使用者。

## 整體風格

| 面向 | 指示 |
|---|---|
| 互動 | **Motion-Driven**：轉場、換月／換週、篩選結果變化都以動態呈現，不是瞬間跳換 |
| 細節 | **Micro-interactions**：hover、收藏、切換、篩選開關等都要有回饋動畫 |
| 美術 | ~~Spatial UI 半透明玻璃~~ → **2026-10-30 改為極簡扁平**（見檔尾「扁平化改版」）：實色表面、必要的陰影，沒有漸層與玻璃模糊；空間感改由游標傾斜／視差表現 |
| 排版 | **Feature-Rich Showcase**：以封面圖為主角、資訊密度高的展示型版面 |

仍須遵守的限制：
- 使用者全域規則：不用米色／奶油色背景、標題斜體強調字、01／02／03 編號段落標籤、等寬字體小標籤、膠囊形按鈕。
- 動畫要尊重 `prefers-reduced-motion`，且不能讓 `test:a11y` 退步。

## 發售月曆

參考 <https://gamecalendar.app/> 與 [`references/calendar-gamecalendar-app.webp`](references/calendar-gamecalendar-app.webp)：
- 月份網格，**每個日期一格只顯示一款遊戲**（封面滿版、遊戲名、平台圖示、標籤如 Early Access／DLC）。
- 同日有多款時，**在格內左右切換**同日的其他遊戲（格底用點點指示目前第幾款）。
- 沒遊戲的日期顯示空格；今天要有明顯標示；上方左右切換上／下個月。

## 時間軸

參考 <https://www.igdb.com/timeline> 與 [`references/timeline-igdb.png`](references/timeline-igdb.png)：
- 垂直中軸、以「週」為單位，上下按鈕切換上一週／下一週，可跳到指定日期、回到今天。
- 每個發售日一張封面卡片，**左右交錯**掛在中軸上，以橫線連到對應日期節點；卡片頂端顯示當日發售數量（如「24 RELEASES」）。
- 卡片可帶標籤（Early Access、Port、Remaster 等）；上方有平台篩選。

## 2026-10-17 追加指示（使用者）

- **網站名稱**：遊戲圖鑑 GameDex（zh-Hant「遊戲圖鑑 GameDex」、en「GameDex」、ja「ゲーム図鑑 GameDex」）。
- **首頁**：參考 IGDB 首頁，顯示「即將上市」「最新上市」「近期活動」「近期熱門」等區塊；月曆移到自己的分頁（`/[locale]/calendar`），首頁不再導向月曆。
- **帳號頁**：參考 IGDB 的個人頁結構，我的清單、遊玩紀錄、我的追蹤、我的遊戲、行事曆、設定等以**同一頁內的分頁**呈現，不跳到別的頁面。
- **平台分類**：Switch、Switch 2 這類混合型平台同時放在「主機」與「掌機」分類，不獨立成一類。
- **活動時間**：依使用者本地時區顯示（登入者用帳號時區，訪客用瀏覽器時區），下一行以小字補充 UTC 時間。
- **組織首頁**：之後會有組織首頁，遊戲圖鑑是其中一個服務，掛在**子網域**（例如 `gamedex.<組織網域>`）；網站要能設定指回組織首頁的連結。
- **效能**：月曆頁 HTML 目前 1.7 MB（整月 1,129 筆全送），改版時每格只先送第一款，其餘按需載入。

## 2026-10-18 追加指示（使用者）

- **iCal 產品識別與頁尾署名**（SoK Studio）不改名。
- **活動時間**：只顯示一行本地時區時間，並標註本機時區（例如「GMT+8」）；不再顯示 UTC 行。
- **Header**（參考 Holodex，見 `references/header-holodex.webp`）：左側品牌旁一個小格的**下拉切換選單**（月曆、時間軸、熱門、遊戲、平台、活動等）取代整排導覽；右側只保留**語言切換按鈕**與**帳號按鈕**，兩者各自是下拉選單（未登入時帳號選單內是登入／註冊）。桌機與手機一致，不再用收合抽屜。
- **全遊戲列表頁**（新頁）：首頁「最新上市」的「查看更多」連到這裡。預設**依上市日期分組分欄**並自動捲到今天的日期；分組可切換為**上市日期／平台／廠商**；要有篩選功能（沿用既有篩選）。廠商分欄只列使用者選定的大廠，其餘歸「獨立／其他」。
- **舊的時間軸 API**（`/api/timeline/*` 與舊後端）刪除。
- **背景**：不要「很像 AI 的漸層」；採方案 A（手把按鍵符號漂浮）＋彩蛋與隱藏主題，細節見 `easter-eggs.md`。
- **Header 右側**：主題、語言、帳號三個下拉按鈕並排。
- **全遊戲列表廠商分欄**：名單與歸屬規則見 `publisher-groups.md`。
- **評分排名分頁**（2026-10-18 追加、使用者定案）：表格式排名，欄位為 **IGDB 分數（預設排序）**、**站內玩家平均**；Metacritic 模組啟用時再多 **Metascore**、**Userscore** 兩欄。使用者點欄位標題即依該欄排序（可升降冪）。效能允許時，切換排序以簡易移動動畫（FLIP）呈現每列位置變化，並標示相對上一個排序標準的名次上升／下降；`prefers-reduced-motion: reduce` 時不做位移動畫，只保留名次變化標示。要有篩選功能（沿用既有篩選），**最低票數門檻由使用者在篩選中自行調整**（給一個合理預設值）。
- **月曆預設不顯示活動**（2026-10-18 追加）：月曆上方提供「遊戲」「活動」兩個顯示開關，預設只開遊戲；開關狀態放在網址參數（可分享、切換月份保留），使用者也可同時打開兩者。

## 2026-10-18 追加指示（二）（使用者）

- **遊戲詳情頁補資訊**（參考 IGDB，截圖 `references/game-detail-igdb-*.{png,webp}`；使用者決定一次做完，等新欄位回填好再一起上）：
  - 公司分三欄：**主要開發商**、**發行商**、**協力開發商**（現在是一個清單加角色文字）。
  - 新增：**類型（Theme）**、**遊戲人數（Game Modes）**、**玩家視角（Player Perspectives）**、**遊戲引擎**、**各語言標題（Localized Titles）**、**其他稱呼（Alternative Titles，含註記）**、**故事簡介（Storyline）**。
  - **其他版本（Editions）**：顯示「查看另外 N 個版本」，點開後在本頁列出相關內容，依關係分組（擴充版、DLC、資料片、重製、移植、合輯…，參考 `game-detail-igdb-related.webp`）；本身是 DLC 或衍生版本時，在此欄標註是哪種版本並連回本體。

- **標題語言一致**：介面是哪個語言就顯示那個語言的標題，抓不到才退回原名。原因是繁中名稱只在同步時計算、舊資料沒重算；2026-10-18 已對開發 DB 重算（1,693 款補上 zh-Hant），之後規則有改要能全庫重算。

## 2026-10-23 修正指示（使用者）

- **全遊戲列表**：不另開頁面；改造既有「遊戲」頁（`/games`），維持列出所有遊戲，新增依**上市日期／平台／廠商**分組檢視（可配合篩選）。先前做的 `/releases` 頁面刪除。首頁「最新上市」的「查看更多」改連到**時間軸 30 天前的那一週**。

## 2026-10-30 扁平化改版（使用者）

- **品牌拉霸機**：開頭的「Game」固定不動，只有後綴（Dex／Calendar／Timeline…）逐字滾動；兩邊不是都以 Game 開頭時才整串滾動。
- **全站扁平化**：移除背景環境光（`body::before` 漸層）、玻璃半透明與模糊（`--glass` 改實色、`--glass-blur: none`）、封面佔位與裝飾條的漸層；封面上的文字改放在實色深色底（`--scrim`）上。保留的漸層只有彩蛋（`eggs.css`、收藏彩虹框）與文字截斷的 mask 淡出。
- **沉浸感來自互動**：游標傾斜＋封面反向視差（`kernel/ui/pointer-fx.tsx`，只在細緻指標且沒有減少動態時）、捲動連動視差與進場滑入（CSS `animation-timeline: view()`，只動 transform）。
- **精簡工具列**（參考 AniList；先做 `/games`，其他頁面的篩選面板仍就地展開）：搜尋＋年份＋排序一列小控制項；篩選是圖示鈕（徽章顯示已套用數量），面板從按鈕下方浮出、點外面或 Esc 關閉；分組切換縮成小型分段控制。
- **卡片大小切換**（`/games` 不分組時）：只看封面／詳細卡片（預設）／清單，三個圖示鈕；同一份 markup，靠 `<html data-gd-view>` 切 CSS，選擇存 localStorage（首次繪製仍是預設，載入後才套用）。
- 待做：時間軸、月曆、平台／廠商頁、評分排名等其他列表的精簡工具列與大小切換（等使用者確認 `/games` 的樣子再推廣）；`gd-view` 切換時的首次繪製閃一下可用 `<head>` inline script 解決。

## 2026-10-31 第二輪調整（使用者實測後）

- **拉霸機**：「Game」固定；單字 340ms、逐字錯開 ≤ 25ms（總長 ≤ 約 480ms）、緩動改 ease-in-out、填充字母 3 個。原本 170ms＋expo-out 太快，看起來像 glitch。
- **封面模式**用 `cover.medium`（264×374）：伺服器在 `<img data-m>` 帶中圖網址，切到封面模式時 `view-switch.tsx` 才換 src；`/games` HTML 約 +2 KB（24 張），html-budget-a 通過。
- **排序**（參考 AniList）：`sort-menu.tsx`——左邊箭頭切升降冪、右邊文字開選單換排序標的。方向用新的排序值表示：`popularity_asc`／`release_date_desc`／`name_desc`（`FILTER_SORTS`、`BROWSE_SORTS`、repository ORDER BY 同步）。換標的時回到該標的的預設方向。沒有 JS 時只顯示目前排序（可改網址）。
- **篩選**：全站按鈕改成同一個圖示小按鈕（`.filter-summary`，高 2rem、徽章顯示數量）；`/games` 浮出面板，其他頁仍就地展開。**每個篩選欄位預設折疊**（`Fold`，原生 details，沒有 JS 也能展開），已有選值的自動展開。
- **依日期分組**：只留一顆顯示目前起算月的按鈕，點開跳出月曆（年份 ‹ ›＋12 個月連結，`month-picker.tsx`）；移除「往前看較早月份」連結與年／月下拉＋前往表單（`gfrom` 網址參數不變）。
- **按鈕標準規格**：`btn-primary／btn-secondary` 高 2rem、字 0.8125rem、方角 `--radius-sm`、無額外陰影；`filter-chip`、`tw-date／tw-kind／tw-nav`、`rc-order-item`、`rc-switch`、`rk-sort`、`cal-switch`、展開鈕等同一規格。**不動**：帳號表單欄位、卡片上的追蹤按鈕（手機 44px 觸控目標，D83）、header。

## 2026-10-31 第三輪調整（使用者）

- **排序控制**：同一個框內「左側方向三角（▲升冪／▼降冪，可直接點擊切換）＋排序標的（點開選單）」；選單中再選一次目前標的也會切換升降冪。不分組（`sort-menu.tsx`）與依平台／廠商（`group-sort-menu.tsx`）同樣式。
- **工具列對齊**：`/games` 的搜尋、年份、送出、排序、篩選、卡片大小全部同一高度（2rem）、頂端對齊；排序說明小字在表單內、不影響右側按鈕位置。
- **分組卡片**（依日期／平台／廠商）：下方名稱資訊底預設隱藏，滑鼠懸浮、鍵盤聚焦、觸控輕觸（第一次輕觸只浮現、再輕觸才進入）時才出現；沒有封面的卡片一律顯示。

## 2026-10-31 第四輪：拉霸機改成真正的捲軸效果（使用者提供參考影片）

- 每個字母是一條依字母順序連續往上滾的捲軸（…C D E F…），垂直動態模糊（SVG `feGaussianBlur stdDeviation="0 1.7"`，只在前 70% 套用），由左到右依序停下（第 0 格 600ms，每格多 80ms，後綴 8 字約 1.2 秒），停下時衝過頭 0.28 列再回彈。取代原本「≤ 0.5 秒、滾過 2 個填充字母」的設計（`brand-roll.tsx`）。
- 排序框：方向三角左側留白拉到 2rem 寬（三角兩側各約 11px），與右側 12px 接近。

## 2026-10-31 第五輪：拉霸機只轉兩三格、方向依導覽順序

- 每個字母從舊標題的字轉到新標題的字，中間最多經過 2 個字母（沿字母表平均分布；同字母不轉）；單字 450ms、逐字多 60ms，後綴 8 字約 0.9 秒。
- 方向：新標題在導覽下拉裡排在舊標題後面＝往上轉（新字從下方進來）；排在前面＝往下轉；不在清單裡＝往上（`rollDirection`）。
